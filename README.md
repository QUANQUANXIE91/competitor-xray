# competitor-xray（竞对X光）

竞对官网深度拆解与抢单话术生成器 —— 输入竞对官网 URL + 我方品类，产出**五块拆解报告**：他是谁 → 他伺候谁 → 他卖什么/不卖什么 → 打他哪 → 怎么开口。

内置**海关数据实测层**（可插拔数据源）：官网说什么是他自己写的，海关记录是他真发过的货。海关快照回灌五块拆解，把推断数字换成实测数字。

## 五块拆解

| 块 | 内容 |
| --- | --- |
| ⓪ 海关快照 | 出口记录/目的国/买家集中度/HS 分布/趋势/抬头变体（海关实测） |
| ① 家底判定 | 身份（贸易商/工贸/工厂）/ 档次 / 主战场 / 核心能力 |
| ② 买家画像 | 他做哪几类买家 + **你挤得进哪条缝** |
| ③ 产品矩阵 | 产品线梳理 + 缺位机会清单（5 类，每类带切入写法） |
| ④ 软肋四连 | 每条溯源到③的缺位，四条挑一条主攻 + 打法落地句 |
| ⑤ 抢单话术 | 以快打慢 / 错位竞争 / 信任锚点，每条附可直接说出口的句子 |

## 触发词

拆解竞对 / 竞对分析 / 盯对手 / 对手透视 / competitor xray / 抢单话术

## 海关数据层（Step 0）

| 取值 | 数据源 | 谁买单 |
|------|--------|--------|
| `fumamx`（默认） | 孚盟MX 海关数据（走 `fumamx-discovery` 技能 CLI） | 使用方自备账号 |
| `custom` | 自购海关数据渠道（贸小七/环球慧思/Panjiva/ImportGenius/52wmb 等），查询结果贴入 `customs_data` | **使用方自理** |
| `off` | 不跑海关层，报告标注"未经海关数据验证" | — |

> ⚠️ **本技能不内置任何海关数据账号——只管"数据怎么拆"，不管"数据从哪来"。** 转给其他团队/客户使用时，使用方需自行采购海关数据服务（孚盟MX、贸小七、环球慧思等均可），通过 `customs=custom` 接入。

## 数字纪律（红线）

- 话术里推断数字（产能/交期/质保/MOQ）必须标注"推断值"，用前替换为真实台账
- 海关实测数字标注「海关实测（数据源，时间窗）」后可直接进话术
- **FOB 报关金额 ≠ 售价**，禁止用海关金额推断对手报价高低

## 与同类技能的分工

| 技能 | 打谁 | 何时用 |
|------|------|--------|
| website-xray | 客户（买家） | 给客户写信前 |
| **competitor-xray（本技能）** | 竞对（对手） | 客户拿竞对压价、标单里有对手、战略复盘 |
| competitor-news-monitor | 竞对 | 拆解完觉得"这家值得长期盯"再升级监测档 |
